ChainTrace

SIH26146 Prototype 🔒 100% Offline

Offline Bitcoin Forensic Lead Detection — fusing network-layer and blockchain-layer signals into ranked, explainable investigative leads.

⚙️ How It Works

1. Data Ingestion & Fusion — fuses raw Bitcoin transaction logs + wallet addresses (Elliptic/Elliptic++) with synthetic network-layer metadata (IP, port, GeoIP, ASN).

2. Unified Graph Construction — builds a NetworkX entity-transaction graph mapping wallets ↔ transactions ↔ IP endpoints.

3. Louvain Community Detection — groups wallets into topological clusters to surface laundering rings and fan-out structures.

4. Ensemble ML Scoring — blends Random Forest illicit probability + Isolation Forest anomaly score + Louvain cluster risk bonus.

5. Explainable Lead Generation — extracts top feature importances per node for human-readable "why flagged" explanations, plus a rule-based intent-archetype pattern match (not a trained crime-type classifier).

🔒 100% offline — zero external API dependencies, runs locally on a standard CPU laptop, air-gapped network defense architecture.
